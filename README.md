
# NOVA - Smart Personal Assistant 🤖

## Project Description
NOVA is a Python-based personal assistant created using Python. It interacts with users through the terminal and provides useful and fun features.

## Features
- Personalized greetings
- Interactive chatbot
- Mood checking
- Study motivation and tips
- Mini quiz with score tracking
- Random jokes
- Motivational quotes
- Mini calculator
- Progress tracking

## Technologies Used
- Python
- Random module
- Datetime module

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   python nova.py

5. Enter your name and type `menu` to see the available features.

## Project Files
- `nova.py` - Main Python program
